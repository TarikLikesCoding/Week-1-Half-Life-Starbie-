# Week-1-Half-Life-Starbie
Learning PCB's through Hack Club's Half Life program, currently working on week 1.

# What is it?
The Starbie I made is a little robot pet that you can carry anywhere. It has a lithium 3.7V battery that can be recharged. The Starbie is a robot pet with visuals on it small OLED screen, and can be interacted with using the two buttons on it and by motion of the pet. I made it with the purpose of learning how to make PCB's and made it truly mine by exploring convenience features like mobility and rechargability of it.

# How does it work?
My Starbie comes with two buttons that are used to move through the menu and interact with the actual pet inside my Starbie. There is an OLED to see the Starbie reacting to my inputs and give visuals to the project. There is a XIAO ESP32 that does all the processing in a compact chip. There are other components such as MPU-6050 and DHX711 to give the Starbie features like temperature sensing and overall motion sensing. It has a battery charging module and a LiPo battery to run when the Starbie is not connected to the laptop.
